# Customer-support guide

## Verify before disclosure

For signed-in customers, use authenticated ownership. For guest orders, use the protected tracking mechanism and the minimum additional identity checks approved by the client. Never search/read another customer's order merely from a guessed order number.

## Common cases

| Request | Support action |
|---|---|
| Product availability | Check current catalog/branch inventory; do not promise reservation from WhatsApp alone. |
| Restock alert | Confirm the customer selected the exact size/colour/option. The alert is one SMS, expires after 90 days and does not reserve stock. Customers can cancel through the management link shown in the browser that created the request. |
| Town parcel quote | Find the protected quote by its reference and verify ownership. During Mon-Sat 8:00 AM-6:00 PM the response target is 30 working minutes. Branch staff publishes the verified operator, collection point, fee and ETA. No order/payment/reservation exists until the customer accepts the current total. If overdue, help through the quote's WhatsApp escalation link without treating the conversation as proof of an order or payment. |
| S18 pickup | Confirm second floor S18, selected slot and paid-item two-working-day hold. Saturday counts; Sunday does not; public-holiday handling remains manual/pending policy. |
| Payment pending | Check system payment state. Do not request an OTP or accept screenshots as proof. Escalate exact provider evidence to authorized reconciliation staff. |
| Accidental order | The protected tracking page allows self-cancellation for ten minutes only while the order is unpaid and not being packed. If M-Pesa was approved, evidence is uncertain, or the window ended, escalate to staff; never promise an automatic refund. |
| Missing callback | Tell the customer not to place a duplicate order while status is investigated. |
| Pickup code | Never read it from logs or disclose it to an unverified caller. Repeated failed attempts require manager support. |
| Delivery dispute | Record facts and escalate; do not mark customer-confirmed. |
| Return | Seven-day self-service applies only to explicitly eligible non-clothing goods. Other products use support review. No automatic refund is promised. |
| Privacy request | Direct the customer to `/accounts/privacy/` and the configured privacy contact. Verify identity before export/correction action. |

## Store policy reminders

Pickup is normally S18, Gaberone Plaza. Paid items are held two working days. Customers/riders should bring item photo and official payment evidence, inspect size/colour/condition before leaving, and follow the published returns wording. Legal/consumer-policy wording still requires client/legal approval before launch.

Use WhatsApp number `0116 153 335` for help and delayed-quote escalation. Commercial quote terms belong in the platform. Staff must not create a hidden parcel order or treat WhatsApp messages, screenshots or typed references as payment proof.

Never request passwords, OTPs, full payment-provider payloads or unnecessary personal data. Record only the information needed to resolve the case.
